# Советское Ралли

Аркадные псевдо-3D гонки в одном HTML-файле.

## Как играть
1. Скачайте файл `soviet-rally.html`.
2. Откройте его двойным кликом в любом браузере (Chrome, Firefox, Edge) — интернет не нужен.

## Управление
- ← → или A / D — руль
- ↑ / W — газ, ↓ / S — тормоз
- P — пауза, R — рестарт, M — звук

7 отечественных машин (Жигули, Нива, ЛуАЗ, ГАЗель, гоночные ВАЗ) и 4 трассы: просёлок, лес, город, трасса.
